# shopping-mall-project

> JSP/Servlet과 Oracle DB를 활용한 쇼핑몰 웹 프로젝트 | 2학년 프로젝트

## 제작 기간

**2026. 07. 11 ~ 2026. 09. 12**

## 프로젝트 소개

Java와 JSP/Servlet을 활용하여 상품 조회부터 장바구니, 배송정보 입력, 주문 완료까지의 흐름을 구현한 온라인 쇼핑몰 **ILLYA**입니다.

Oracle Database와 연동하여 회원·상품·게시판 데이터를 저장하고 관리하며, 일반 회원과 관리자의 권한에 따라 이용할 수 있는 기능을 구분했습니다.

## 사용 기술 및 도구

| 구분 | 사용 기술 및 도구 |
| --- | --- |
| 웹 화면 | HTML, CSS, JavaScript |
| 서버 개발 | Java, JSP, Servlet |
| 데이터베이스 | Oracle Database |
| DB 연동 | JDBC, PreparedStatement |
| 웹 서버 / 실행 환경 | Apache Tomcat 9 |
| JSP 태그 라이브러리 | JSTL |
| 파일 업로드 | COS 라이브러리 (`cos.jar`) |
| 상태 관리 및 공통 처리 | Session, Cookie, Servlet Filter |

## 주요 기능

| 구분 | 구현 내용 |
| --- | --- |
| 회원 관리 | 회원가입, 로그인·로그아웃, 회원정보 조회·수정, 회원 탈퇴 |
| 입력값 검증 | 회원가입 입력값 검사, 아이디·이메일·전화번호 중복 검사 |
| 상품 관리 | 전체 상품 조회, 상세 조회, 상품명·설명·제조사·카테고리·상품 ID 검색 |
| 관리자 기능 | 상품 등록·수정·삭제, 상품 이미지 업로드, 가격·재고 수정 |
| 접근 권한 관리 | 로그인 상태 유지, 관리자 전용 화면 및 상품 관리 기능 접근 제한 |
| 장바구니 | 상품 추가, 수량 변경, 개별 삭제, 전체 비우기, 합계 계산 |
| 주문 | 배송정보 입력, 주문정보·금액 확인, 주문 완료 시 재고 차감 |
| 재고 관리 | 주문 수량과 재고 확인, 여러 상품의 재고 일괄 차감 |
| Q&A 게시판 | 게시글 작성·조회·수정·삭제, 검색, 페이징, 조회수 관리 |
| 게시판 권한 | 로그인한 사용자만 글 작성, 작성자 본인만 글 수정·삭제 |
| 조회수 중복 방지 | 같은 Session에서 동일 게시글을 반복 조회해도 조회수 중복 증가 방지 |
| 기타 | 한국어·영어 전환, UTF-8 인코딩 필터, 요청 정보 수집 필터, 404·500 오류 페이지 |
